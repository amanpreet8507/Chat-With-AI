# Chat-With-AI
An AI-driven chat app built using Google's Gemini API and SwiftUI for a smooth, responsive UI. The app enables natural conversations with AI, offering smart responses and seamless user interaction. Integrated a simulator for testing and debugging, ensuring a flawless user experience.🚀
Features:
✅ AI-powered chat responses using Google Gemini API
✅ SwiftUI-based intuitive user interface
✅ Real-time message handling for smooth interactions
✅ Built-in simulator for efficient testing and debugging
